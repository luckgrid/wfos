# Agents navigation pattern

Reusable seed for the machine-readable navigation layer used by automated workers. It contains
profile, skill, tool, and graph contracts—not repository instructions.

Humans and automated workers enter a repository or package through its maintained `README.md`.
`ontarch agents-init` materializes this pattern into a working `$AGENTS_HOME`, usually
`<workspace-root>/.agents/`, so automated sessions can resolve narrower scope and policy data.

## Seed and working copy

| Concern | Home |
|---|---|
| Repository and namespace guidance | owning `README.md` files and normal docs |
| Machine routing, policies, schemas, and generated registry | Ontarch package |
| Reusable navigation seed | `packages/ontarch/patterns/agents/` |
| Applied profiles, skills, tools, and graph pointers | `$AGENTS_HOME` |

Ontarch descriptors and policies remain the machine-routing authority. The working `.agents/`
layer lets an operator or automated worker discover which profiles, skills, tools, and graph
projections are available for the current workspace.

## Seed layout

```text
patterns/agents/
├── PATTERN.toml       pattern identity and version
├── profiles/          profile contract and generic examples
├── skills/            skill contract, examples, and reusable bodies
├── tools/README.md    generated local-toolkit contract
└── graphs/README.md   generated graph pointer
```

The pattern intentionally does **not** include or generate a repository instruction file. The
repository owns its README hierarchy; the pattern owns reusable automated-worker data contracts.

## Materialization

```bash
moon run ontarch:agents-init
# or
packages/ontarch/bin/ontarch agents-init [--target DIR] [--force]
```

Initialization:

- copies README contracts and generic example records into `$AGENTS_HOME`;
- writes `.pattern-lock` with the pattern id and version;
- skips existing files unless `--force` is supplied;
- leaves reusable skill template bodies in the pattern for resolver fallback;
- never writes `local-toolkit.yml`, which is generated by `ontarch sync`.
